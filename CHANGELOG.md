# Changelog

## v1.1.0 — 29 October 2026

The main documentation now describes the unified independent-CFD experiment for one, three and seven vessels.

- Shared 64/16/32 chemical inlet-case split and three separately trained seeds per topology.
- Fixed ordinary numerical C0 comparisons on identical blood inputs within each topology.
- Th/Fg/Fn forward predictions and 1/2/3-site sparse inverse results.
- Source code, numerical tables, publication figures and a clean English group presentation.
- Checksummed generated reference data and unchanged model weights in release assets.
- Portable output directories, direct three-vessel raw-input extraction, and separate replay, retraining and full-generation routes.
- Frozen-public-package regression checks against the completed experiment.

Publication does not retrain or modify the selected networks. Historical v1.0 weights, C1 results, raw-input reproduction and release assets remain available.

## v1.0.0 — 26 October 2026

Initial single-vessel neural-closure release, calibrated C1 comparison and equal-parameter graph/pointwise controls. Later historical records add biochemical retraining and raw-input reproduction.
